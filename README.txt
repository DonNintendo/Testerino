PHEONIX HOME SERVICES WEBSITE

FILES
- index.html
- styles.css
- script.js
- assets/

HOW TO OPEN
Double-click index.html.

HOW TO PUBLISH
Upload all files and folders to your web host's public website folder, or upload the folder to GitHub Pages / Netlify.

IMPORTANT
- The contact form opens the visitor's email app and does not store submissions.
- The service map uses Leaflet and OpenStreetMap and needs internet access to load map tiles.
- Brand badges are local website graphics based on the brands visible in the supplied photos.
- Keep the assets folder next to index.html.
