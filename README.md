# Pheonix Home Services Website

Static, responsive website prepared for GitHub Pages.

## Publish on GitHub Pages

1. Upload all files and the `assets` folder to the root of your GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. Add `SWFLPheonix.net` under **Custom domain** after your domain DNS is pointed to GitHub Pages.

## Contact form

The form opens the visitor's email application with the request already filled in. This works on GitHub Pages without a server and does not store customer information.
